Mobile devices such as tablets or mobile phones (in desktop mode) are increasingly being used in various configurations as compact client-side systems for accessing 
a wide range of online resources. This is reflected in the availability of numerous corresponding VDI clients (remote desktop access e.g. for RDP, FreeRDP, VNC) for 
iOS and Android.

With the development of an open-source Virtual Desktop Infrastructure, which is intended to be accessed via the open-source SPICE protocol, there is some interest to
make access possible on mobile devices as well. SPICE currently offers two access options: a [classic standalone client](https://www.spice-space.org/download.html)
and an [HTML5 client](https://www.spice-space.org/spice-html5.html). However, neither variant yet includes the newly developed full-video transport model created within 
the OSVDI project, which would be central to meeting the current requirements.
